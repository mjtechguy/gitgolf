## Initial decisions and limits

See [ADR 0001](decisions/0001-initial-forge-and-vertical-slice.md). The bootstrap REST/native-history exceptions are retired by [ADR 0002](decisions/0002-generated-api-and-typed-navigation.md): existing operations use generated Connect contracts, SQLC queries and TanStack Router. Wider service schemas, identity and tenant policy remain future work. AES-GCM protects the stored upstream credential using the configured key, with authenticated session binding. The keyring increment above adds a qualified bounded rotation workflow; live OAuth exchange across activation or restore, production/Kubernetes cutover, broader recovery topologies, external secret stores and FIPS remain unqualified. The bounded Docker backup/restore proof above restores key configuration/metadata and invalidates application credentials before reopening. Browser authentication now supports a configured Gitea authorization-code/S256-PKCE application, with explicit scoped consent, single-use PostgreSQL state/browser binding and encrypted rotating credentials; token bootstrap remains. See [ADR 0003](decisions/0003-gitea-oauth-and-session-refresh.md). The separate operator-enrolled local-password increment above adds Golf-owned password sign-in; generic external OIDC, CLI managed authentication and complete account lifecycle remain open.

Local HTTP requires explicit loopback-only insecure-cookie configuration. Remote deployment requires HTTPS. Credentials stay server-side, cookies are HttpOnly/SameSite, all RPC requests require the exact configured Origin before decoding, and authenticated upstream redirects are refused. These controls and tests do not constitute a full security audit.

Compose and Helm use separate database roles, non-root runtimes and persistent PostgreSQL/Gitea volumes. The Kubernetes chart shares the byte-identical initialization script and supports operator-managed external dependencies. The bounded Docker recovery runbook, PostgreSQL safeguards and full native fresh-restore/whole-stack restart drill pass. Kubernetes recovery, production TLS/controller integration, version upgrades and node/storage fencing still need qualification. StatefulSet identity and RWO claims do not establish partition fencing; manually forced stateful replacement is not supported by this evidence. Gitea Actions remains disabled; Golf executes its own bounded manually admitted catalog. Product CI does not authorize adding repository CI workflows.
