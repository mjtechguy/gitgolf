## Scope and reading the matrix

The route tree is defined by [router.tsx](../web/src/router.tsx); [navigation.ts](../web/src/navigation.ts) generates links; [App.tsx](../web/src/App.tsx) chooses the authenticated workspace and lazy page components. Repository subviews share [RepositoryBrowser](../web/src/RepositoryBrowser.tsx); account, repository and organization settings share [AccountSettings](../web/src/AccountSettings.tsx); instance administration shares [InstanceSettings](../web/src/InstanceSettings.tsx).

`O/R` below means the actual repository owner/name, `ORG` the organization name, `N` a canonical positive issue/PR number, `SHA` a full lowercase 40- or 64-character object ID, `RUN` a lowercase UUIDv4 and `TEAM` a canonical positive signed-64-bit decimal ID. These are placeholders, not working fixture URLs. Query parameters and fragments must be constructed with the shared navigation helpers rather than string interpolation. Repository/native IDs are immutable authority bindings; friendly names and observed ref names do not grant access.

Every data-bearing page needs these comparison states, in addition to the row-specific variants below:

| State | Required observation | Evidence constraint |
| --- | --- | --- |
| Populated/current | Actual authorized observations; short and long names/text; enough rows to reveal density and paging | A fulfilled Playwright RPC fixture proves UI handling, not a live provider |
| Empty | A real empty inventory or supported empty resource; distinguish loaded-page filter zero from whole-resource zero | Never manufacture a count from the displayed page |
| Loading/revalidating | Initial session/page load, lazy component fallback and current-authority revalidation | Private content must not be visible as authorized while a required authority check is unresolved |
| Error | Backend unavailable, malformed/incomplete receipt and unavailable optional section | Do not present an error as an empty collection or successful integration |
| Denied/revoked | Signed-out, expired session, private outsider, supported read-only actor and access removed while open | Capture removal of previously visible private content and editors, not only an initial 403 |
| Explicit editing | Add/New/Edit open, cancel, validation, pending, confirmed receipt, stale revision, unknown outcome and explicit inspection | A screenshot cannot prove native dispatch count, CAS or durable receipt semantics |
| Navigation | Link, reload, Back/Forward, bookmark, alias and malformed deep link | Invalid route selectors should fail before protected resource RPCs; readable ref resolution is a separate contract |
| Responsive/accessibility | Both themes at matched 1280/390 widths; useful 1920/320 edge checks; keyboard/focus and long content | Keep readable text and Golf styling; no document overflow, with intentional inner code/table scrolling |

Where a page has no editor, the editing row is not applicable. Where an empty state is impossible by contract, test explicit missing/error rather than faking an empty successful result. Permission requirements in this inventory describe the minimum fixture categories; the backend's current supported-API checks remain authoritative.

### Source address and alias contracts

- Canonical immutable source addresses use `tree/SHA/PATH` or `blob/SHA/PATH`. Named RS-2 addresses use the decoded suffix, with internal explicit `refKind=branch|tag` and `refName=NAME` when a namespace is known. An untyped named suffix must enumerate complete valid namespace/split candidates, not guess the longest ref or probe path existence. The in-progress RS-2 UI is source work at this checkpoint; it must earn its own final served proof. [Readable source design](READABLE_SOURCE_URL_DESIGN.md), [qualification matrix](READABLE_SOURCE_URL_QUALIFICATION_MATRIX.md).
- `/repositories/O/R` remains a readable legacy query-view entry point. Its `view=source|commits|issues|pulls|actions|compare`, `ref`, `path`, `historyPath`, `issue`, `issueNew`, `pull`, `pullView`, `commit`, `run`, `step` and state/return-context fields map to the same components. This alias is not a separate feature implementation. Generated links use canonical work URLs; source normalization must retain exact selections and literal paths.
- The canonical empty-tail `/O/R` also accepts supported legacy query view selectors. Encoded detail/source paths remove redundant view/detail/ref query fields; deliberate branch/tag/return context remains. Test contradictory query selectors, duplicate fields, malformed percent encoding and hash preservation without silently selecting a second ref.
- Canonical issue/PR path numbers are positive and at most signed-32-bit. The legacy issue query preserves its established unsigned-32-bit range. Native IDs elsewhere stay exact signed-64-bit decimal strings. Commits require full lowercase 40/64 SHA, runs require lowercase UUIDv4, and selected step is an integer from 0 to 49.
- Exact snapshot identity does not turn a friendly route into a current branch lock. Background live changes signal new activity; pinned source/comparison must not silently move. Explicit Latest, permalink and reload semantics require separate observations.
